# Airline Flight Delay & Operations Analysis

> End-to-end analysis of US airline flight delays using Python, SQL window functions, and Power BI to uncover key delay drivers by airline, airport, and day of week.

## Objective
Analyze US domestic flight delay patterns to identify the biggest drivers of delays by
airline, airport, and time period.

## Dataset
[Airline Delay and Cancellation Data, 2009-2018](https://www.kaggle.com/datasets/yuanyuwendymu/airline-delay-and-cancellation-data-2009-2018) (Kaggle)

## Tools
Python (Pandas), SQL (SQLite window functions), Power BI, Google Colab

## Process
1. Cleaned and transformed raw flight records (500K+ rows)
2. Ran SQL window-function queries to rank the worst-delay airports per airline
3. Built a Power BI dashboard tracking on-time performance, delay trends, and top delay causes
